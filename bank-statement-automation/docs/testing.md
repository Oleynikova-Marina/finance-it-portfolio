# Синтетические тесты и контроль качества

Тестовый контур проекта проверяет два обезличенных формата выписок: БАНК 1 и БАНК 2. Все значения и операции в демонстрационных книгах вымышлены.

## Запуск из корневой папки проекта

```bash
python -m pip install -r requirements.txt
python scripts/generate_fixtures.py
python scripts/clean_bank1.py
python scripts/clean_bank2.py
python scripts/verify_demo.py
```

Генератор создаёт исходные книги в `test-data/BANK1/source/` и `test-data/BANK2/source/`. Обработчики сохраняют результаты в соответствующие папки `output/`.

## Отчёты

После проверки формируются:

- `test-data/BANK1/qa_report.json` — проверки формата Банка 1;
- `test-data/BANK2/qa_report.json` — проверки формата Банка 2;
- `test-data/qa_summary.json` — общий результат.

В опубликованном контрольном отчёте зафиксировано **23/23 PASS**: БАНК 1 — 11/11, БАНК 2 — 12/12. Это сохранённый результат конкретного синтетического набора, а не подтверждение запуска после текущего перемещения файлов. После перестройки структуры требуется повторно выполнить команды выше.

## Хранение данных

В репозитории остаются только JSON-отчёты. Создаваемые XLSX-файлы в каталогах `source/` и `output/` исключены из Git через корневой `.gitignore`. Не помещайте сюда реальные банковские выписки или рабочие книги.
