# Finance & IT Portfolio

**Практическая автоматизация финансовых процессов, Python-разработка и бизнес-аналитика.**

## Профессиональный профиль

Финансовый специалист с практическим опытом автоматизации финансовых и учётных процессов с использованием IT-инструментов.

Моя профессиональная специализация — объединение финансовой экспертизы, Python-разработки, Excel и аналитического подхода для решения прикладных бизнес-задач.

## Ключевые компетенции

- Автоматизация финансовых и учётных операций.
- Разработка Python-скриптов для обработки данных.
- Автоматизация работы с Excel.
- Интеграция программных решений с внешними сервисами и API.
- Сверка банковских платежей и контроль задолженности.
- Анализ финансовых данных и визуализация показателей.
- Оптимизация бизнес-процессов.

## Технологический стек

**Языки и инструменты:** Python, SQL (в процессе развития).

**Работа с данными:** Excel, openpyxl, pandas.

**Автоматизация:** pathlib, datetime, регулярные выражения, pywin32.

**Интеграции:** REST API, банковские API, Outlook COM.

## Практические проекты

### 01. Автоматизация обработки банковских выписок и подготовки писем Outlook

Разработка последовательного процесса для подготовки банковских выписок к передаче коллегам.

**Этап 1 — обработка Excel-выписок:**
- фильтрация строк по содержимому столбца «Дебет»;
- удаление операций по заданному текстовому правилу;
- очистка технических значений и удаление итоговых строк;
- обработка книг с объединёнными ячейками;
- сохранение очищенных файлов отдельно от исходников.

**Этап 2 — подготовка письма:**
- сбор обработанных Excel-файлов;
- выбор почтовой учётной записи Outlook;
- заполнение получателей и темы;
- добавление файлов во вложения;
- сохранение письма в «Черновиках» без автоматической отправки.

**Результат:** повторяющиеся операции по очистке файлов и подготовке письма автоматизированы; финальная проверка и отправка остаются за сотрудником.

Демонстрационный код, единая архитектурная схема с Outlook и синтетические тесты находятся в [папке проекта](bank-statement-automation/).

### 02. Автоматизация сверки банковских платежей и задолженности

Проект автоматизации сопоставления финансовых обязательств с фактическими банковскими платежами, группировки задолженности и контроля оплат.

**Статус:** разработка и совершенствование решения.

### 03. Получение банковских остатков через API

Разработка решения для получения информации об остатках на расчётных счетах из нескольких банков с использованием Python и API.

**Статус:** проект в разработке.

### 04. Финансовая аналитика и визуализация

Анализ задолженности, динамики финансовых показателей и распределения данных по городам. Разработка аналитических представлений и визуализаций.

**Статус:** развитие аналитического проекта.

## Подход к работе

Я рассматриваю автоматизацию не только как написание программного кода, но и как решение конкретных бизнес-задач.

В каждом проекте важны:
- понимание исходного финансового процесса;
- определение правил обработки данных;
- проектирование алгоритма;
- разработка и тестирование решения;
- оценка практического результата.

## Цель профессионального развития

Развитие в направлении Finance & IT, финансовой автоматизации, бизнес-аналитики и разработки прикладных решений для бизнеса.
