# Результаты тестирования

**Дата проверки:** 20.11.2026  
**Среда:** Windows, Python 3.15, openpyxl 3.1.5, Excel COM / pywin32.  
**Набор данных:** полностью синтетические демонстрационные Excel-файлы.

## Проверенный сценарий

1. Генератор создал тестовые книги для платёжного плана и двух банковских выписок.
2. Скрипт `prepare_workbook.py` подготовил рабочую книгу: перенёс 7 строк.
3. Контрольная сумма исходного столбца L до сверки составила **396 500,00**.
4. Скрипт `reconcile_bank_payments.py` прочитал две выписки и выполнил сопоставление по сумме и городу; дата банковской операции могла отличаться от плановой.
5. Результаты сохранены в Excel-книге; сводный лист `total` создан и проверен через Excel COM.

## Проверка нормализации городов

Визуально проверено отображение города в столбце `рс` на листах `data` и `send`: префикс `ОБЩИЙ,` удаляется, город отображается в нормализованном виде (например, `МОСКВА`).

## Предупреждение при запуске

Во время обновления форматирования листа `total` Python вывел `DeprecationWarning` для метода `copy` у объекта форматирования openpyxl. Предупреждение не остановило выполнение: книга была сохранена, открыта и проверена через Excel COM. В дальнейшем вызов следует заменить на актуальный способ копирования форматирования.

## Вывод

Основной демонстрационный сценарий успешно пройден на синтетических данных. Проверены подготовка книги, чтение двух форматов выписок, однозначное сопоставление, защитное поведение при неоднозначности, перенос и физическое удаление строк, обновление сводного листа и нормализация отображаемых городов.

Результат относится к указанному тестовому набору и не означает исчерпывающего тестирования всех возможных форматов банковских выписок и граничных случаев.
