**Дата проверки:** 20.11.2026  
**Среда:** Windows, Python 3.15.0, openpyxl 3.1.5, pywin32 312, Excel COM (Excel 16.0).  
**Набор данных:** полностью синтетические демонстрационные Excel-файлы.

## Проверенный сценарий

1. Генератор создал тестовые книги для платёжного плана и двух банковских выписок.
2. Скрипт `prepare_workbook.py` подготовил рабочую книгу: перенёс 7 строк.
3. Контрольная сумма исходного столбца L до сверки составила **396 500,00**.
4. Скрипт `reconcile_bank_payments.py` прочитал две выписки и выполнил сопоставление по сумме и городу; дата банковской операции могла отличаться от плановой.
5. Результаты сохранены в Excel-книге. Скрипт сообщил об успешном открытии исходной и временной книг через Excel COM; после выполнения содержимое листов дополнительно проверено чтением сохранённой книги через openpyxl.

## Проверка листов после сохранения

Сохранённая книга повторно прочитана через openpyxl. В ней присутствуют три листа: `total`, `data` и `send`.

- **Лист `data`:** осталось 3 неперенесённые группы; значение `L1` — **135 500,00**.
- **Лист `send`:** перенесены 4 исходные строки по 3 группам; для каждой группы сформирована строка итога. Сумма перенесённого долга — **261 000,00**.
- **Лист `total`:** сводные значения по городам (тыс. руб.) — SPB: 72; EKATERINBURG: 39; KAZAN: 25; ИТОГО: 136.

## Проверка нормализации городов

Визуально проверено отображение города в столбце `рс` на листах `data` и `send`: префикс `ОБЩИЙ,` удаляется, город отображается в нормализованном виде (например, `МОСКВА`).

## Предупреждение при запуске

Во время обновления форматирования листа `total` Python вывел `DeprecationWarning` для метода `copy` у объекта форматирования openpyxl. Предупреждение не остановило выполнение: книга была сохранена, скрипт сообщил об успешном открытии книг через Excel COM, а сохранённое содержимое листов было проверено через openpyxl. В дальнейшем вызов следует заменить на актуальный способ копирования форматирования.

## Вывод

Основной демонстрационный сценарий успешно пройден на синтетических данных. Проверены подготовка книги, чтение двух банковских выписок, однозначное сопоставление, защитное поведение при неоднозначности, перенос и физическое удаление строк, обновление сводного листа, нормализация отображаемых городов и чтение результатов из сохранённой книги.

Результат относится к указанному тестовому набору и не означает исчерпывающего тестирования всех возможных форматов банковских выписок и граничных случаев.
