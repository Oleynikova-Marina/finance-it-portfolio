# Бизнес-процесс

## Входные данные

### Платёжный план
Рабочая книга Excel с листом данных. Для группировки используются поля:
- юридическое лицо;
- плановая дата оплаты;
- расчётный счёт;
- сумма задолженности.

### Банковские выписки
Файлы Excel из поддерживаемых источников. Для поиска операции используются дата, сумма списания, сведения о плательщике/получателе и назначение платежа — в зависимости от структуры конкретной выписки.

## Выходные данные

- Реестр групп, для которых найдено однозначное соответствие.
- Исходный список обязательств без подтверждённого соответствия.
- Сводная история сумм по аналитическим направлениям (в демонстрационной версии — по городам).
- Журнал выполнения с количеством обработанных файлов, операций, групп и результатов сопоставления.

## Правило принятия решения

| Результат поиска | Действие |
|---|---|
| Найдено ровно одно подходящее списание | Группа переносится в реестр подтверждённых оплат |
| Совпадений нет | Группа остаётся в исходном списке |
| Найдено более одного совпадения | Группа остаётся в исходном списке для ручной проверки |
| Группа уже присутствует в реестре | Повторное добавление не выполняется |

## Важное бизнес-ограничение

Плановая дата входит в ключ группировки обязательств, но дата фактической банковской операции может отличаться от плановой даты. В текущем алгоритме подтверждение выполняется по сумме и текстовому признаку города в назначении платежа; дата банковской операции не обязана совпадать с плановой датой.
