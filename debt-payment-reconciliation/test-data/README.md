# Тестовые данные проекта 02

В этой папке находится генератор полностью синтетических Excel-файлов. Он создаёт входную и рабочую книги для `prepare_workbook.py`, а также план и две банковские выписки для `reconcile_bank_payments.py`.

## Создание файлов

Из корня репозитория выполните:

```powershell
py -m pip install openpyxl
py debt-payment-reconciliation/test-data/generate_test_data.py
```

Генератор создаст папки и файлы рядом со скриптами проекта:

- `debt-payment-reconciliation/scripts/input/Исходные_данные_тест.xlsx`
- `debt-payment-reconciliation/scripts/working/Рабочая_книга_тест.xlsx`
- `debt-payment-reconciliation/scripts/data/plan/План_20.11.2026_ТЕСТ.xlsx`
- `debt-payment-reconciliation/scripts/data/bank_1/Выписка_Банк_1_ТЕСТ.xlsx`
- `debt-payment-reconciliation/scripts/data/bank_2/Выписка_Банк_2_ТЕСТ.xlsx`

## Контрольные проверки

Для `prepare_workbook.py` ожидаются 7 строк данных и сумма `data!L1 = 396 500,00`.

Сценарии для сверки:

1. Компания 1, Москва: две строки 100 000 + 50 000 образуют группу 150 000 — однозначное совпадение.
2. Компания 1, СПБ: два банковских платежа по 72 000 — неоднозначность, группа должна остаться на `data`.
3. Компания 1, Екатеринбург: сумма 39 000 есть в выписке, но назначение содержит Казань — совпадения по городу нет.
4. Компания 1, Казань: подходящего платежа нет.
5. Компания 2, Москва-Сосенки: 85 000 — проверка совпадения по части названия города.
6. Компания 2, Казань: 26 000 — проверка русскоязычных заголовков выписки.

Все компании, контрагенты, документы и ИНН вымышлены. Тестовые ИНН: `9900000001`, `9900000002`, `9900000003`.

Скрипт `reconcile_bank_payments.py` уже содержит эти синтетические ИНН в настройке `COUNTERPARTY_INNS`, поэтому для запуска на книгах, созданных этим генератором, менять список не требуется. Если вы создаёте собственные тестовые выписки, замените список на соответствующие вымышленные ИНН.

Скрипт физически удаляет подтверждённые строки с листа `data`. Для каждого повторного теста восстанавливайте исходную чистую копию файла из генератора. Для запуска сверки нужны Windows, установленный Excel и `pywin32`.
