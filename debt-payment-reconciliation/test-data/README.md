# Тестовые данные проекта 02

В этой папке находится генератор полностью синтетических Excel-файлов. Он создаёт входную и рабочую книги для `prepare_workbook.py`, а также план и две банковские выписки для `reconcile_bank_payments.py`.

## Создание файлов

Из корня репозитория выполните:

```powershell
py -m pip install openpyxl
py debt-payment-reconciliation/test-data/generate_test_data.py
```

Генератор создаст папки и файлы рядом со скриптами проекта:

- `debt-payment-reconciliation/scripts/input/Исходные_данные_тест.xlsx`
- `debt-payment-reconciliation/scripts/working/Рабочая_книга_тест.xlsx`
- `debt-payment-reconciliation/scripts/data/plan/Report_20.11.2026_ТЕСТ.xlsx`
- `debt-payment-reconciliation/scripts/data/bank_1/Выписка_Банк_1_ТЕСТ.xlsx`
- `debt-payment-reconciliation/scripts/data/bank_2/Выписка_Банк_2_ТЕСТ.xlsx`

## Контрольные проверки

Для `prepare_workbook.py` ожидаются 7 строк данных и сумма значений столбца L на листе `data` — `396 500,00`.

Сценарии для сверки:

1. Компания 1, Москва: две строки 100 000 и 50 000 образуют группу 150 000. В плане указаны МСК и МОСКВА, в назначении платежа — Москва. Проверяется нормализация сокращения.
2. Компания 1, Санкт-Петербург: в плане полное название, в назначении — СПБ. Два платежа по 72 000 создают неоднозначность; группа остаётся на `data`.
3. Компания 1, Екатеринбург: в плане указано ЕКБ, но назначение операции на 39 000 содержит Казань. Совпадения по городу быть не должно.
4. Компания 1, Казань: подходящего платежа на 24 500 нет; группа остаётся на `data`.
5. Компания 2, Москва: в плане указано МОСКВА, в назначении платежа — МСК. Проверяется нормализация сокращения в назначении.
6. Компания 2, Казань: операция на 26 000 проверяет обработку русскоязычных заголовков банковской выписки.

Все компании, контрагенты, документы и ИНН синтетические. Тестовые ИНН: `9900000001`, `9900000002`, `9900000003`.

Скрипт `reconcile_bank_payments.py` уже содержит эти синтетические ИНН в настройке `COUNTERPARTY_INNS`, поэтому для запуска на книгах, созданных этим генератором, менять список не требуется. Если вы создаёте собственные тестовые выписки, замените список на соответствующие синтетические ИНН.

Скрипт физически удаляет подтверждённые строки с листа `data`. Для каждого повторного теста восстанавливайте исходную чистую копию файла из генератора. Для запуска сверки нужны Windows, установленный Excel и `pywin32`.
