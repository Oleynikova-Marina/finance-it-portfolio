# Скрипты проекта 02

Оба скрипта обезличены. В них нет рабочих путей пользователя, реальных названий организаций, банковских идентификаторов или реальных ИНН. Перед запуском настройте только синтетические/тестовые значения под свою копию файлов.

## 1. Подготовка рабочей книги

Файл: `prepare_workbook.py`

Структура рядом со скриптом:

```text
scripts/
  prepare_workbook.py
  input/
    <один исходный Excel-файл>
  working/
    <одна целевая рабочая книга с листом data>
```

В каждой из папок `input` и `working` должен находиться ровно один файл Excel формата XLSX или XLSM. Скрипт переносит строку заголовков и данные, приводит значения столбцов J и L к числам, сортирует записи по столбцу B, скрывает заданные столбцы и пересчитывает сумму в L1. Дополнительный treemap выключен по умолчанию.

## 2. Сверка с банковскими платежами

Файл: `reconcile_bank_payments.py`

Структура рядом со скриптом:

```text
scripts/
  reconcile_bank_payments.py
  data/
    bank_1/
      <банковские выписки>
    bank_2/
      <банковские выписки>
    plan/
      <одна рабочая книга Excel>
```

В папке `plan` должен быть ровно один файл XLSX или XLSM. В нём необходим лист `data` с заголовками `Юрлицо`, `Дата оплаты по плану до`, `Долг по отгр`, `рс`. Для даты отчёта в имени файла должна присутствовать дата в формате ДД.ММ.ГГ, ДД.ММ.ГГГГ или ГГГГ-ММ-ДД.

Перед запуском откройте скрипт и настройте:

- `LEGAL_ENTITY_FILTERS` — названия организаций из тестовой книги, например `("КОМПАНИЯ 1", "КОМПАНИЯ 2")`.
- `COUNTERPARTY_INNS` — список тестовых ИНН контрагентов. По умолчанию список пуст, поэтому банковские платежи не пройдут фильтр, пока вы не зададите тестовые ИНН.
- Папки `bank_1` и `bank_2` соответствуют организациям `КОМПАНИЯ 1` и `КОМПАНИЯ 2` в настройке скрипта. Если меняете названия папок, обновите соответствующую логику определения организации в `load_bank_rows()`.

Скрипт сопоставляет сумму группы с суммой одной банковской операции и ищет город из поля `рс` в назначении платежа. Несколько отдельных банковских списаний не суммируются. В лист `send` переносятся только группы с ровно одним найденным совпадением; неподтверждённые и неоднозначные группы остаются на `data`. Обновляется лист `total`.

## Зависимости и среда

- Python 3.10 или новее.
- `openpyxl`.
- `pywin32` для второго скрипта.
- Windows с установленным Microsoft Excel для выполнения Excel COM-операций во втором скрипте.

Установка:

```powershell
py -m pip install openpyxl pywin32
```

Запускайте скрипты из установленной среды Python. Перед первой проверкой используйте копии книг и синтетические данные. Закройте рабочую книгу в Excel перед запуском скрипта сверки.

## Важное предупреждение

Это публикация исходного кода, а не подтверждение готовности к эксплуатации на любых банковских форматах. Проверьте структуру заголовков, соответствие юридических лиц, тестовые ИНН, точность поиска города и суммы, резервное копирование и корректность итоговых листов на искусственных примерах. Не загружайте в публичный репозиторий реальные выписки или рабочие книги.
