# Синтетические банковские выписки — демонстрация

В этом каталоге опубликован воспроизводимый набор тест-кейсов для двух обезличенных форматов банковских выписок.

## Содержимое архива

`synthetic_bank_statement_cleanup_demo.zip` включает:
- исходную синтетическую выписку и результат обработки для BANK1;
- исходную синтетическую выписку и результат обработки для BANK2;
- два независимых Python-скрипта очистки;
- JSON-отчёты по каждому кейсу;
- независимый скрипт `verify_demo.py`;
- инструкции и зависимости.

Все данные вымышлены. Для примеров BANK2 использованы тестовые ИНН с заведомо неверной контрольной цифрой. Реальные банковские реквизиты, названия банков, учётные данные и рабочие пути не включены.

## Как повторить

1. Скачайте и распакуйте архив.
2. Перейдите в распакованную папку `synthetic_bank_statement_cleanup_demo`.
3. Установите зависимость: `python -m pip install -r requirements.txt`.
4. Запустите оба обработчика и проверку:

```bash
python BANK1/scripts/clean_bank1.py
python BANK2/scripts/clean_bank2.py
python verify_demo.py
```

Проверяющий скрипт выводит результат каждого условия и завершает работу с кодом ошибки, если хотя бы одна проверка не пройдена.

## Ограничения

Это демонстрация на двух фиксированных синтетических структурах, а не универсальный парсер банковских форматов. Перед применением к другой форме выписки требуется отдельная настройка и тестирование.
