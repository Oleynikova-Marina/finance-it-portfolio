# Синтетические банковские выписки — демонстрация

Воспроизводимый набор тестов для двух обезличенных форматов Excel-выписок. Все данные вымышлены; реальные банковские документы, реквизиты и рабочие пути не используются.

## Состав проекта

- `generate_fixtures.py` — создаёт синтетические исходные книги BANK1 и BANK2.
- `clean_bank1.py` — обработчик формата BANK1 с сохранением допустимых объединений ячеек.
- `clean_bank2.py` — обработчик формата BANK2.
- `verify_demo.py` — независимая проверка результатов и формирование JSON-отчётов.
- `requirements.txt` — зависимости.

Excel-книги создаются локально и не хранятся в Git. Это позволяет повторить тест с нуля и не размещать даже синтетические табличные документы в истории репозитория.

## Запуск

Требуется Python 3.10+.

```bash
python -m pip install -r requirements.txt
python generate_fixtures.py
python clean_bank1.py
python clean_bank2.py
python verify_demo.py
```

Генератор создаёт исходные книги в `BANK1/source` и `BANK2/source`. Обработчики сохраняют результаты в `output` соответствующего банка. Проверяющий скрипт выводит каждое условие и завершает работу с кодом ошибки, если хотя бы одна проверка не пройдена. JSON-отчёты записываются в `BANK1/qa_report.json`, `BANK2/qa_report.json` и `qa_summary.json`.

## Контрольные данные

**BANK1:** входящий остаток — 1 250 000; после очистки остаются документы 1001 и 1004 на общую сумму 505 000. Удаляются дебетовые операции на 2 140, внутренний перевод на 50 000 и итоговый блок.

**BANK2:** входящий остаток — 875 000; поступления — 441 000; списания — 48 200; исходящий остаток — 1 267 800. После очистки остаются документы ПЛ-2001 и ПЛ-2004 на 316 000. Перевод между собственными счетами и строки после исходящего сальдо удаляются.

**Последний проверенный прогон: 23/23 PASS** (BANK1 — 11/11, BANK2 — 12/12).

## Безопасность и ограничения

Используются условные обозначения BANK1/BANK2, тестовые номера документов и вымышленные контрагенты. Тестовые коды контрагентов имеют формат `TEST-xxx`; ИНН, КПП, банковские счета, реальные адреса, токены и пароли в примерах отсутствуют.

Это демонстрация двух фиксированных структур, а не универсальный банковский парсер. Новый формат выписки требует отдельной настройки правил и тестирования.
