# Автоматизация банковских выписок

Практический проект автоматизации финансовой операции: обработка двух разных форматов банковских выписок, единый запуск и подготовка черновика Outlook.

## Состав проекта

- `bank_1_cleaner.py` — формат Банка 1: удаление строк с заполненным «Дебет» в области операций, очистка значения под «Входящий остаток на начало дня», исключение переводов собственных средств, удаление итогового блока начиная с «Количество операций». Учитываются объединённые ячейки.
- `bank_2_cleaner.py` — формат Банка 2: удаление строк с заполненным «Дебет», очистка ячейки справа от «Входящее сальдо», исключение переводов между собственными счетами, удаление блока от «Исходящее сальдо».
- `main.py` — последовательный запуск обоих обработчиков и предложение создать черновик.
- `outlook_draft.py` — создание черновика Outlook с Excel-файлами из общей папки результатов. Письмо не отправляется.
- `config_example.py` — образец локальной конфигурации.

## Установка и запуск

1. Установить зависимости: `pip install openpyxl pywin32`.
2. Скопировать `config_example.py` в `config.py`.
3. Заполнить в локальном `config.py` пути, адрес отправителя, получателей и подпись.
4. Создать входные папки, указанные в настройках, и положить туда соответствующие файлы `.xlsx`.
5. Запустить `python main.py` из папки проекта.
6. Проверить полученные файлы и черновик в Outlook.

## Безопасность

В публичном репозитории используются только условные обозначения и тестовые адреса-заполнители. Не публикуйте исходные выписки, реквизиты, токены, пароли, реальные адреса, локальный `config.py` или пути к рабочим папкам. Исходные книги не перезаписываются: результаты сохраняются отдельно. Черновик требует ручной проверки и не отправляется автоматически.

## Ограничения

Поддерживаются файлы `.xlsx`. Макросы, внешние связи и нестандартные элементы книг требуют отдельной проверки. Скрипты рассчитаны на две конкретные структуры выписок, а не на произвольные банковские форматы. Перед рабочим использованием протестируйте их на обезличенных копиях и проверьте каждое правило очистки.
